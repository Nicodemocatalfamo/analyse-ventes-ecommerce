
# Analyse des ventes e-commerce

Projet réalisé dans le cadre de ma **certification Data Analyst**.

## Présentation

Ce projet consiste à analyser les ventes d’un site e-commerce à partir d’un tableau de bord et de données commerciales afin d’identifier les principaux résultats et de les restituer de manière claire.

L’objectif était de transformer les données disponibles en informations compréhensibles pour un interlocuteur métier et de produire une synthèse exploitable.

## Démarche

Le projet comprend notamment :

- l’analyse des indicateurs présents dans le tableau de bord ;
- l’interprétation des résultats commerciaux ;
- l’identification des tendances principales ;
- la création de graphiques adaptés aux données ;
- la synthèse des résultats ;
- la préparation d’une restitution à destination d’un manager.

## Compétences mises en œuvre

- Analyse de données commerciales
- Interprétation d’indicateurs
- Analyse de ventes
- Création de graphiques
- Synthèse de résultats
- Restitution métier
- Communication de conclusions à un interlocuteur non technique

## Contenu du dépôt

Le dépôt comprend :

- le fichier Excel utilisé pour l’analyse ;
- une présentation synthétisant les résultats ;
- un document de restitution destiné au manager.

## Ce que ce projet démontre

Ce projet montre ma capacité à analyser des indicateurs commerciaux, identifier les informations importantes et restituer les résultats de manière claire à destination d’un décideur.

Il met également en avant ma capacité à adapter la présentation des données à un besoin métier.

**Outils :** Excel · Analyse de ventes · Data visualisation · Reporting · Restitution métier
